# Tilen Jäger — Portfolio

Osebni portfolio Tilna Jägerja, študenta informatike in tehnologij komuniciranja
na FERI ter tehnika mehatronike.

## Vsebina

- predstavitev, znanja in izobrazba,
- galerije projektov z lightbox prikazom slik,
- dvojezični slovenski in angleški vmesnik,
- odzivna postavitev za računalnike in mobilne naprave,
- povezava do CV-ja in kontaktnih kanalov.

## Izbrani projekti

- **Avtomatski hranilnik za domače živali** — ESP8266, Arduino, Flutter in 3D tisk,
- **Osebni portfolio** — HTML, CSS in JavaScript,
- **ComfortFriends** — aplikacija za dnevne izzive, napredek in povezovanje prijateljev.

## Tehnologije

Projekt je izdelan z uporabo HTML5, CSS3 in JavaScripta brez zunanjega
JavaScript ogrodja.
